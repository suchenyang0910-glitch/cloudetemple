# Pet garden place

[已验证事实] `demo.html` reads `/api/pet-garden/memorials` by default. Add `?sample=1` only for the visibly marked local sample data; a failed or empty read shows an empty garden and creates no placeholder memorials.

[用户决定] The pet garden owner may use the shared walking, camera, billboard and label helpers from `../shared.js`. Shared town files and the hall directory are outside this directory's scope; request shared-file changes through the queue.

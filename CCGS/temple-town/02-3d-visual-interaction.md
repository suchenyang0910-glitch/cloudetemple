# 3D 视觉与交互方向

> ⚠️ **3D 交互部分已被 `v3-02-3d-worship-interaction.md` 取代**（2026-11-11）。本文档中"不做自由漫游"、"三固定视角"等结论已过期；环境声、主尊阶段、分享卡等章节仍有参考价值。

> 状态：DRAFT · 创意方向，**不是技术选型**。引擎、渲染管线、具体性能数值由 technical-director 决定。
> 下面所有「档位」「数值」都是创意侧给出的意图，等技术评审后再换成正式预算。

## 1. 镜头

**原则**：镜头受控、慢、对称优先（P3「尊重先于炫技」）。移动端不做自由漫游。

| 视角 | 构图 | 运动 | 用途 |
|---|---|---|---|
| **正面** | 中轴对称，主殿占画面中部，主尊剪影在门内（远景） | 进入时从低机位慢慢推近（约 3–5 秒，可跳过）；停稳后可以轻微陀螺仪视差（±3°，可关闭） | 默认视角、礼拜、上香 |
| **侧面** | 三分构图，殿侧山墙 + 专属地标（菩提树 / 莲池 / 海 / 灯阶 / 泉 / 花市 / 塔群）占一侧 | 横向轨道平移，用户左右滑动，带边界 | 看景、拍分享卡 |
| **院子** | 低机位、广角感，地面纵深，主殿退到画面后方 | 固定机位 + 小范围前后推拉 | 独有仪式发生地（放灯、点灯、行禅、写心事） |

- 三个视角之间切换用**交叉淡化 + 轻微位移**（约 0.6–1 秒），不做长距离飞行镜头（容易晕，也贵）。
- **主尊的镜头禁区**：不仰拍特写、不从脚下穿过、不从背后看、不做环绕 360°、不让 UI 压在主尊身上。正式造像之前，主尊在画面中的高度不超过画面高度的 1/4（剪影阶段刻意保持远景）。
- 进入任何寺，第一个镜头都给到**专属地标**，用来立刻建立「这是哪座寺」的识别（P1）。

## 2. 场景层级

从远到近，每一层都能独立降级：

| 层 | 内容 | 降级方式 |
|---|---|---|
| L0 天空 | 渐变天空、太阳 / 月亮、星 | 低档：一张渐变 + 一个发光点 |
| L1 远景 | 远山、海平面、城镇屋顶 | 低档：一张分层贴图（2.5D 卡片） |
| L2 中景 | 寺庙主体（模块套件）、专属地标 | 低档：减面 LOD + 烘焙光照 |
| L3 主尊 | 剪影 / 正式造像 | 不降级到「看不清」；低档用剪影卡 |
| L4 近景交互物 | 香炉、灯、莲灯、纸船、花枝、步道 | 交互物永远保留，只减少装饰 |
| L5 粒子与氛围 | 云雾、香烟、花瓣、萤火、海雾 | 低档：粒子数量大幅减少，雾改成半透明渐变卡 |
| L6 UI | 仪式按钮、时段、分享 | 不降级 |

## 3. 时段切换

- **四时段**：晨 / 日 / 昏 / 夜。
- **默认跟随本机时间**（时段边界做成可调的 Tuning Knob，比如 05:00 / 08:00 / 17:00 / 19:00，待调），用户可以手动切换并锁定。
- **每寺有一个「代表时段」**：云寺 = 晨、莲池 = 昏、观音 = 晨、地藏 = 夜、药师 = 日、弥勒 = 日、南传 = 晨昏。第一次进入时如果当前时段不是代表时段，给一句轻提示（「这座寺在黄昏最好看」），**不强制**。
- **实现意图**：每个时段是一组预设（天空渐变、主光方向和颜色、雾的颜色和浓度、调色 LUT、灯是否点亮、环境声混音）。切换时在两组预设之间插值，约 2–3 秒。**不依赖实时全局光照**。
- **夜间**：灯光是主角（长明灯、莲灯、灯笼、塔身灯带），这是夜间的「回报」。

## 4. 环境声

| 寺 | 底层（共用） | 主音（专属） | 仪式声 |
|---|---|---|---|
| 云寺 | 风、远鸟 | 晨钟 | 早课（现有） |
| 莲池 | 风、水 | 水波、蛙鸣 | 念佛计数：每点一下一声轻木鱼 / 磬（音色待定） |
| 观音 | 风 | 海浪、海鸥、风铃 | 纸船入水 |
| 地藏 | 低频风 | 夜虫、灯芯微响 | 点灯「嚓」一声，非常轻 |
| 药师 | 风、竹 | 山泉 | 落笔、卡片翻面 |
| 弥勒 | 人声底噪（混成一片、无清晰语句） | 花市、孩子笑声、远处鞭炮 | 花枝摇动、小铃 |
| 南传 | 风、蝉 | 僧院钟、风铃 | 脚步（随行禅节奏） |

- 时段会影响混音：夜间底层降低、主音更近。
- **禁止**：可识别的真实法师 / 僧人诵经录音（除非有授权）；哀乐、哭声；带歌词的流行曲。
- 所有声音默认可静音；静坐模式可以只留主音。

## 5. 主尊：剪影到正式造像的演进

| 阶段 | 内容 | 准入条件 |
|---|---|---|
| **S0 抽象占位**（当前） | 光环圆 + 简化身体轮廓 + 莲座 / 台座；单色或渐变；**无面部、无手印、无持物** | 无（默认） |
| **S1 风格化剪影** | 加入姿态区分（坐 / 立）、大致比例；仍然没有面部细节 | 顾问确认：姿态、比例、是否可以用剪影这种方式表现 |
| **S2 线稿 / 体块** | 手印、持物、衣纹的大致结构 | 每尊一份**造像规范**（手印、坐姿、持物、配色、南北传差异）由顾问签字 |
| **S3 正式造像** | 最终模型 / 插画 | 规范签字 + 美术总监审核 + 顾问复核终稿 |

**所有阶段的通用规则**：
- 主尊不做表情动画、不眨眼、不说话、不跟手势互动。
- 主尊不能是可点击按钮；仪式的交互物是香炉、灯、蒲团，不是主尊本身。
- 主尊不被裁切（尤其是头部），不出现在画面最底部，不被 UI 覆盖。
- 分享卡上的主尊同样遵守这些规则。
- 南传主尊用独立的造型规范，不复用北传。

## 6. 活动状态（通用状态机）

所有仪式（通用 + 独有）共用一套状态：

```
[不可用] --时段/开放条件满足--> [可进行] --用户开始--> [进行中] --完成--> [今日已完成]
                                     ^                                      |
                                     +----------- 第二天 / 用户再做一次 ------+
[节庆态]：叠加在以上任一状态上，只改变场景（装饰、灯）和文案，不改变规则
```

- 「不可用」只能因为**时段**或**该寺还没开放**，**不能因为没付费**（见总体规划 §7）。
- 「今日已完成」可以再做，不设上限；**没有**「断签」状态。
- 「进行中」可以随时退出，不提示「功德未圆满」。
- 每种独有仪式的进行方式：
  - 计数型（莲池念佛）：点一次 +1，可清零。
  - 放置型（莲灯、纪念灯）：一次放一盏，场景里留下可见的痕迹（当天）。
  - 书写-释放型（观音写心事）：写 → 确认 → 动画 → 本机删除文字。
  - 书写-保留型（药师祝愿卡）：写 → 生成卡片（只保留在用户本地 / 用户选择分享）。
  - 选择-发送型（弥勒迎新春）：选花 → 生成问候卡。
  - 节奏型（南传行禅）：跟着节拍一步一步，绕一圈结束。

## 7. 分享卡

- **版式**：竖版 9:16（故事）+ 4:5（信息流）两种。
- **内容层级**：寺名（越南语）→ 一句文案 → 场景缩略（当前时段）→ 主尊剪影（小，居上，不裁切）→ 脚注（小镇名）。
- **不在分享卡上放**：未核实的日期、任何功效表述、用户写的心事（观音寺）、逝者的完整个人信息（地藏寺只允许用户自己填的称呼，可留空）。
- 草稿阶段的分享卡全部带「Bản nháp / 草稿」水印。

## 8. 移动端性能降级（创意意图）

| 档 | 目标设备（待技术评审） | 视觉 | 必须保留 |
|---|---|---|---|
| 高 | 近两三年的中高端机 | 完整 3D、动态粒子、时段插值、轻视差 | — |
| 中 | 主流中端机 | 3D 减面 + 烘焙光、粒子减半、时段切换改成短淡化 | 地标、主尊、交互物、环境声 |
| 低 | 入门机 / 省电模式 | **2.5D 分层卡片**（每寺每视角每时段一张分层图），粒子换成贴图动画 | 同上；仪式全部可用 |
| 极简 | 网络差 / 存储不足 | 静态插画 + 环境声 | 仪式和分享卡可用 |

- 设计红线：**任何档位，独有仪式都必须能完整做完**。降级只降「好看程度」，不降「能不能做」。
- 资源按寺分包下载；没下载的寺在地图上显示剪影 + 「下载后进入」。
- 越南市场有大量中低端安卓机，**中档和低档要当作主力档位来设计**，不是事后补救（待产品方提供用户设备分布数据确认）。

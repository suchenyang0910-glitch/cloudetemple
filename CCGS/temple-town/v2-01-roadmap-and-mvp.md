## 4. MVP 定义（v2 更新）

v1 的 MVP 定义为"弥勒寺切片赶 Tết"——**此项已被用户否决（Q2）**。

**v2 MVP = 12 月可选弥勒院子小版本（若家族牌位顺利）**

见独立页面 `v2-04-dilac-courtyard-december.md`，本文件不重复。

**v2 正式 Milestone 1 = 弥勒寺完整版，Tết 后上线**

| 范围 | 说明 |
|------|------|
| 场景 | 正面 + 侧面 + 院子 × 4 时段，2D 原画 | [用户决定]
| 仪式 | 通用五仪（上香 L2 流程、礼拜、木鱼、静坐、念珠）+ 迎新春独有仪式（选花 + 笑脸贺卡）| [已验证事实] Q9 |
| 配套 | 节庆贺卡分享、地图外壳（弥勒已开放、其余剪影） |
| 不包含 | 天气同步（默认关闭，可在设置中开启）[已验证事实] |
| 不包含 | Service Worker（v1 范围已移除，v2 再评估）[已验证事实] |
| 文化门槛 | 越南语由太太审核；习俗/仪式顺序须顾问确认后方可上线 |

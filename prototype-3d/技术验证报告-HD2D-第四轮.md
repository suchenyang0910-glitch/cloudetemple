# HD-2D 第四轮小修验证报告

日期：2026-11-07

范围：仅 `codex/three-walk-prototype` 与独立 `/hd2d/` 预览；不进入主线，不改正式环境。

## 已实测

- 375×548 与 393×659 两个可视尺寸的浏览器流程均通过，无横向或纵向滚动、无控制台错误、无第三方运行时请求。
- 礼拜中与坐禅的侧前方镜头里，人物全身、佛座、佛像剪影和背光均完整入画；人物继续面向佛位。
- 大殿六个蒲团已统一为同尺寸的浅草色编织蒲团；侧面坐禅帧移除自带蒲团，不再混用橙棕圆盘或大扁草垫；未观察到黑色裂缝或穿插闪烁。
- 大殿侧前方只显示木地板，左下不再露出院子青石；柱旁白色竖缝已由连续背景层覆盖。
- 375×548：60 FPS，低位约 47.4 FPS，首屏传输 4,568,834 bytes。
- 393×659：60 FPS，低位约 41.0 FPS，首屏传输 4,568,834 bytes。
- 静态资源原始总量 4,975,883 bytes，小于 10 MiB 预算；3 个逻辑测试全部通过。
- 15 秒录屏已生成并由 `ffprobe` 确认为 15.000 秒，大小 775,263 bytes。
- 独立预览已切换到 release `7bb469a6bb07`：未认证 401；认证后 HTML、JavaScript 与 WebP 均为 200、MIME 正确并带 `noindex`；发布包 35 个运行文件通过 SHA-256 校验。
- 公网 393×659 流程复核通过：礼拜与坐禅均保持侧面朝向佛位，页面无滚动、无应用错误。Cloudflare 自动注入的统计脚本被现有 CSP 阻止 1 次，不影响预览功能。
- staging 主站、h5、miniapp 与 API 健康检查均为 200；正式环境 release 仍为 `420a29fb1cf2`。

## 只在代码里确认

- 大殿木地板几何向侧前方镜头覆盖区延伸，避免院子地面从边缘露出。
- 背墙、两侧山景与侧向雾景平面有重叠余量，避免柱旁背景露底。
- 蒲团使用一套几何、材质和编织纹理；没有重叠的第二层蒲团几何。
- 对外预览默认不显示两个本地模拟访客；仅保留显式开发参数供本地性能检查。

## 没把握

- 尚未在真实 iPhone、安卓和 Telegram WebView 上复测第四轮的帧率、内存与长时间运行表现。
- 程序化木地板比原画细节更少；本轮不再继续美术打磨，等待真机反馈后再决定是否继续 3D。
